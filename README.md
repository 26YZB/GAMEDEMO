# GAMEDEMO
开发日志
版本1.0

时间2026.4.22发布
内容简介：使用wasd控制人物移动，鼠标左键攻击，加入连段判定，触碰传送门按下e键会实现两个传送门的传送，敌人原地驻守，进入范围内才会追击，追击状态时，玩家离开一定范围会使敌人返回驻守点，按esc会打开暂停菜单进行设置。
实现简介：使用Unity Input System实现键盘操作，自定义有限状态机实现动画更新（如站立切换跑步），加入了物理角色控制器，基于scriptableobject实现数据管理，敌人基于navmesh实现AI的寻路功能，Unity Trriger和Collider实现攻击，使用UGUI事件监听功能控制UI面板。
项目思考与后续规划：制作时间有限，能力水平有限，存在一些BUG如Unity场景中会渲染生成敌人，但打包之后的项目敌人消失，角色脸部渲染导入出现一些问题，应该是在blender中生成错误（人物模型均为模之屋提供，不会进行任何侵权操作），商店和背包系统正在开发中，后续也会加入对话任务系统的开发，当前为可运行版本，但内容不完整，代码中也存在注释不及时的问题，会后续慢慢修正。
